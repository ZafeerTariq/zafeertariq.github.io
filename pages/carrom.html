Carrom Star

Carrom game with different game modes and leagues.

Try the game here (WIP)

Platform, Technologies, Monetization

  • Developed using Cocos Creator engine for HTML5 platform.
  • Has In-App Purchases on the Yandex Game platform for in-game currency and bundles.
  • Integrated rewarded video and interstitial advertisements at meaningful points in game.

Key Features

  • Features three different game modes.
    • Disc Pool.
    • Carrom Classic.
    • Freestyle.
  • League based progression system.
    • 14 leagues with increasing AI difficulty.
    • Each league has different entry fee and reward structure to encourage player engagement.
  • Adaptive AI.
    • AI difficulty scales based on the current league.
    • Rookie league being the easiest, mythic being the hardest.
  • Two power-ups are available for player to use.
    • Second Strike: grants additional turn when a turn would normally have ended.
    • Enlarge Striker: increases striker size until player turn is over.
  • Three chests are available in game.
    • Daily Chest - one free per day.
    • Basic Chest - available after 3 hours.
    • Premium Chest - available after 8 hours.
    Players can spend gems to unlock the Basic and Premium chests early.
  • Daily Missions System.
    • Three daily missions set each day.
    • Completing each mission grants a key, 3 of which can be used to unlock a chest.
  • Multiple achievements based on gameplay awarding different rewards and unlocking items in shop.
  • Many unlockable striker and table skins using coins and gems.
